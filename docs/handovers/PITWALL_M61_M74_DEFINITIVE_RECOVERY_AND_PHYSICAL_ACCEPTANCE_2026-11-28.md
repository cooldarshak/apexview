## Architecture contract
One authoritative playback/session coordinator and generation fencing. Rust owns stitching, legal atlas assembly, bounded byte/index/position/timing processing, immutable leases and compact storage. Media3 owns MediaCodec and DRM; Kotlin owns Android surfaces, EGL lifecycle, Compose/DPAD, foreground services, Cast SDK and platform callbacks. Native code must remove a copy, retain less or improve proven performance; never just shift heap categories. No new player engine, proprietary SDK, paid OpenF1 or second process to hide PSS. No forced lower source quality, FPS, decoder mode, lost captions/commentary or security downgrade. Authorized protected receiver route only; never read protected pixels into the clear baked encoder. If all supported policies leave vendor floor too high, document floor and request a product decision, never invent reclaimed bytes.
